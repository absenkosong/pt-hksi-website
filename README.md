# PT HASTA KARYA SEJAHTERA INDONESIA (HKSI) - Official Corporate Website & CMS

Website resmi perusahaan **PT HASTA KARYA SEJAHTERA INDONESIA (HKSI)**, didirikan pada Mei 2026 di Kota Cilegon, Banten. Dibangun dengan standar performa enterprise modern, desain mewah flat-gold & royal-blue yang selaras dengan logo resmi perusahaan, serta dilengkapi panel CMS admin terintegrasi.

---

## 🏗️ 3 Divisi Usaha Utama

1. **Supply Material Konstruksi & Industri**
   - Agregat Batu Split (1-2, 2-3, Abu Batu), Base Course LPA/LPB.
   - Pasir Pasang & Cor Mutu Tinggi, Sirtu, dan Tanah Urug Super.
   - Logistik Armada Darat Dump Truck Tronton & Tongkang Laut Kapasitas 2.000 – 7.500 Ton.
2. **Jasa Laboratorium & Pengujian Mutu (SNI & ASTM)**
   - Uji Tekan Beton (Kuat Tekan Silinder & Kubus) dengan Sertifikat Kalibrasi KAN.
   - Core Drill & Uji Karakteristik Beton Terpasang.
   - Penyelidikan Tanah: Sondir CPT (2.5 & 5 Ton), Boring SPT, Sand Cone Density Test, dan Uji CBR.
   - Pengujian Agregat: Uji Abrasi Los Angeles, Sand Equivalent, dan Analisis Saringan.
3. **Jasa Pengukuran & Survei Geospasial Presisi**
   - Survei Topografi Kontur & Pemetaan Lahan Industri.
   - Survei Batimetri Alur Sandar Dermaga & Pelabuhan Cilegon (Multi-beam / Single-beam Echosounder).
   - Staking Out Titik Pancang & Batas Kavling Presisi Tinggi.
   - Pemetaan Udara Fotogrametri & Drone LiDAR.

## 🌐 Struktur Halaman Website (5 Halaman Lengkap)

- **1. Beranda (`/`)**: Hero visual pelabuhan industri Cilegon, highlight 3 pilar layanan, legalitas perusahaan (Kemenkumham RI 2026 & NIB), 4 Nilai Luhur HKSI (Harmoni, Kualitas, Sinergi, Integritas), serta form & tombol kontak WhatsApp cepat.
- **2. Tentang Kami (`/tentang`)**: Sejarah pendirian 2026 di Cilegon, Visi & Misi, kartu legalitas resmi berbadan hukum lengkap (SK Kemenkumham, Akta Notaris, NPWP, NIB), serta bagan struktur organisasi modern (Komisaris, Direktur Utama, Kepala Divisi, Tim Teknis).
- **3. Layanan & Solusi (`/layanan`)**: Detail spesifikasi teknis dan keunggulan tiap divisi bisnis beserta tombol *Request for Quotation (RFQ)*.
- **4. Portofolio & Fasilitas (`/portofolio`)**: Kapabilitas fasilitas lapangan, armada angkut, peralatan laboratorium berkalibrasi KAN, dan galeri proyek percontohan.
- **5. Kontak & Lokasi (`/kontak`)**: Informasi kantor operasional (Komplek Ruko Metro Cilegon Blok B 1 No 07), formulir permintaan penawaran resmi, peta Google Maps interaktif, dan kanal WhatsApp/Email.

## 🔒 Panel Admin (CMS Khusus Manajemen)

- **URL Akses**: `/admin/login` (Akses langsung melalui tautan privat)
- **Kredensial Default**:
  - Username: `admin`
  - Password: `admin123`
- **Fitur Admin**:
  - **Kotak Masuk Penawaran (Leads Inbox)**: Notifikasi pesan penawaran / RFQ dari klien beserta status penanganan (Unread, In Progress, Selesai).
  - **Kelola Layanan**: Tambah, ubah, dan susun urutan katalog layanan perusahaan.
  - **Kelola Portofolio**: Publikasikan proyek dan peralatan baru.
  - **Pengaturan Profil**: Update alamat kantor, nomor telepon, WhatsApp, email, dan legalitas secara dinamis.

## 🚀 Panduan Menjalankan Secara Lokal

```bash
# 1. Install dependensi
npm install

# 2. Jalankan server lokal
node server.js
# atau gunakan script shortcut:
# jalankan-website.bat
```

Buka browser di: `http://localhost:3000`

---

## ☁️ Deploy ke Vercel

Proyek ini telah dikonfigurasi penuh dan siap dideploy langsung ke **Vercel**:

1. Push repository ke GitHub.
2. Buka dashboard [vercel.com](https://vercel.com).
3. Klik **Add New Project** -> **Import Git Repository**.
4. Pilih repository `pt-hksi-website`.
5. Klik **Deploy** (Pengaturan build & serverless telah terkonfigurasi otomatis melalui `vercel.json` dan `api/index.js`).
